# IGMIS Account Data — Extracted CSVs

Generated by `../extract_all.py` from the Excel files in `data_to_seed/Account/`.

## Outputs

| File | Rows | What it contains |
|------|-----:|------------------|
| `students.csv` | 603 | One row per unique student (roll + program + intake). Master record with fee setup + contacts. |
| `payments.csv` | 4,895 | Every individual payment transaction (tuition, application, admission, midterm, NU exam, library). |
| `admission_records.csv` | 271 | Full admission-sheet rows: application + admission fees with dates, contacts, references, waivers. |
| `semester_summary.csv` | 1,236 | **Per-student-per-semester** balances + attendance: opening balance, total received in semester, closing balance, cumulative received, cumulative due, receivable at MT exam, total receivable end of semester, total payable at form-fillup, attendance counts, late-payment fine. **This is the "dues / receivables" data.** |
| `daily_accounts.csv` | 6,916 | Day-by-day cashbook from `Daily account 2024/2025/2026.xlsx` — date, description, exam fee, cash receive, cash expense, running balance. |
| `fee_structure_thm.csv` | 22 | THM fee schedule (reference document). |
| `raw_dump/*.csv` | 95 files | Complete cell-by-cell dump of every workbook/sheet, unprocessed. Use as the source of truth if anything looks wrong in the structured files. |

## Column reference — `semester_summary.csv`

These are the columns the user specifically asked for (dues, payments, receivables, revenues):

| Column | Source column in Excel |
|---|---|
| `opening_balance` | "Xth Semester Opening Balance" — carryover from previous semester |
| `semester_total_received` | "Xth Semester Total Fee Received" — sum of all tuition slots that semester |
| `closing_balance` | "Xth Sem Closing Balance" — balance after semester. Negative = overpaid, positive = dues |
| `cumulative_received_after_semester` | "Total BBA/MBA/CSE Fee Received after Xth Semester" |
| `cumulative_due_after_semester` | "Total BBA/MBA/CSE Fee Due after Xth Semester" — **total receivable across program** |
| `receivable_at_mt_exam` | "Receivable at the time of 1st MT exam" (mostly 14th cohort) |
| `total_receivable_end_of_semester` | "Total fee receivable at the end of semester" |
| `total_payable_at_form_fillup` | "Total Payable at the time of Form fillup" |
| `late_payment_fine_total` | "Late Payment Fine" running total |
| `library_deposit`, `library_fine` | Library columns |
| `classes_present`, `classes_absent`, `percent_absent`, `absence_fine` | Attendance + fine for absence |

> Cells containing `#REF!` (broken Excel formulas in source) are exported as empty.

## Column reference — `payments.csv`

| Column | Notes |
|---|---|
| `roll_number`, `name`, `program`, `intake_batch`, `semester` | Identity + which semester sheet this payment was found in |
| `payment_date` | ISO-format `YYYY-MM-DD` where possible, else original string |
| `amount` | Tk (integer string or 2-decimal) |
| `payment_type` | `application_fee` / `admission_fee` / `tuition` / `mt_exam_fee` / `nu_exam_fee` / `library_deposit` |
| `late_fine` | Per-slot late fine charged for this payment |
| `discount` | Per-slot discount |
| `remarks` | Free-text remark on the row (e.g. "ok", "ok form fill up") |

## Reconciliation tips

- **Per student total paid** = sum of `payments.csv` amounts where `roll_number` matches (filter on `payment_type` to separate tuition vs admission vs exam fees).
- **Per student dues remaining** = latest `closing_balance` (or `cumulative_due_after_semester`) for the student in `semester_summary.csv` ordered by semester.
- **Institutional revenue per month** = sum `daily_accounts.cash_receive` by month, cross-check against summed `payments.payment_date` per month.

## What was NOT structured

The two budget/forecast files (`Actual Picture 23-9-25.xlsx`, `February 2026.xlsx`) are revenue projections, not actual ledger data — their layouts are too irregular to schema-fit. They're available as full raw dumps under `raw_dump/`:

- `raw_dump/Actual_Picture_23-9-25__Sheet1.csv`
- `raw_dump/February_2026__Sheet1.csv` (and Sheet2, Sheet3)

The 95 raw-dump CSVs are the **safety net** — every cell of every sheet, exactly as Excel evaluated it. If a number looks off in `semester_summary.csv`, open the matching raw dump to see exactly what was in that cell.
